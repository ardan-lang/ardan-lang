Welcome 👋

ArdanLang is a systems-style language built with a custom compiler pipeline: AST → IR → Optimizations → Bytecode → VM Execution.

AST

Structured syntax tree for parsing source code.

IR

SSA-like intermediate representation for analysis.

VM

Custom execution engine for bytecode interpretation.
