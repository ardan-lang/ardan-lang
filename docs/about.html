Why ArdanLang?

ArdanLang was designed to explore how modern compilers work internally: from parsing to IR generation, optimization, and virtual machine execution.

Goals

  • Build a clean SSA-based IR system
  • Implement optimization passes (DCE, CSE, folding)
  • Create a lightweight VM for execution
  • Make compiler design easy to understand

Philosophy

Keep it minimal, explicit, and educational — closer to LLVM/V8 concepts but simplified for learning and experimentation.

Built with curiosity and compiler obsession.
